# recovery-lab 1.0

The companion lab for *When Agents Fail: A recovery lab for agents that change real things*
by Tim Urista. Python 3.10 or later, standard library only. No network, accounts or keys.

    cd recovery-lab
    python3 -m lab list
    python3 -m lab check 01

Appendix A of the book covers setup, the runner, and adding your own exercise.

- The book, Kindle and paperback: https://www.amazon.com/dp/B0HQYB5PKR
- Corrections and new versions: https://timurista.ai/labs/when-agents-fail
- Source: https://github.com/timurista/when-agents-fail-lab

The repository is read-only: changes come from the author. Found a bug, a wrong answer
or a confusing exercise? Open an issue on GitHub. Pull requests aren't merged.
